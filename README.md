EXPENSE TRACKER APP

Created 3 separate files:-
  1. index.html - Defines the user interface and structural layout of the application.
  2. index.css - Handles the styling, layout, and visual presentation (linked via the "link" tag)
  3. script.js - Manages the application logic and core functionalities including onAddTransaction, onDeleteTransaction, onEditTransaction and onUpdateTransactionTable.


HOW TO RUN THE APPLICATION:-

To run this project locally, you will need Visual Studio Code (VS Code)

METHOD 1:-
1. Open the project folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click anywhere inside the index.html file.
4. Select "Open with Live Server".

METHOD 2:-
1. Open the project folder in VS Code.
2. At the bottom-right corner of the VS Code window (the Status Bar).
3. Click the "Go Live" button.
